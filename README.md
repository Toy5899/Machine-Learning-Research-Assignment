
# Machine Learning Research Assignment

## Project Overview
This project was completed as part of my Advanced Analytics and Machine Learning studies at BrightLearn.

The assignment focuses on understanding the fundamentals of Machine Learning, its applications, different learning approaches, and the steps involved in building Machine Learning models.

It includes a research report and a practical Python exercise completed in Databricks.

## Project Objectives
- Understand the basic concepts of Machine Learning.
- Explore different types of Machine Learning.
- Understand the Machine Learning workflow.
- Learn about data preprocessing and feature engineering.
- Apply Python techniques to prepare a dataset for Machine Learning.

## Tools and Technologies
- Python
- Pandas
- NumPy
- Scikit-learn
- Databricks
- Canva

## Practical Implementation
The practical exercise involved working with an e-commerce orders dataset using Python in Databricks.

The main steps included:
1. Loading and exploring the dataset.
2. Checking for missing values and duplicates.
3. Cleaning and preparing the data.
4. Encoding categorical features.
5. Splitting the data into training and testing sets.
6. Applying feature scaling using StandardScaler.

## Project Deliverables
- Machine Learning Research Report (PDF)
- Databricks Python Notebook (.ipynb)
- Machine Learning Diagrams

## Key Learnings
Through this assignment, I gained a better understanding of Machine Learning concepts and how to prepare data for model development.

I also improved my practical skills in Python, data cleaning, preprocessing, feature encoding, and splitting datasets for training and testing.

## Conclusion
This assignment helped me connect Machine Learning theory with practical data preparation using Python and Databricks. It provided a foundation for developing and evaluating Machine Learning models in future projects.
